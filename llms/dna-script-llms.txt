# DNA Script

> DNA Script is a synthetic-biology company (founded 2014, Paris FR / South San Francisco US) that
> pioneered Enzymatic DNA Synthesis (EDS), a template-free, water-based alternative to phosphoramidite
> chemistry. Its SYNTAX System is a benchtop DNA printer that synthesizes, desalts, quantifies and
> normalizes up to 96 custom oligos in parallel for same-day, on-premise DNA production. DNA Script
> publishes no public developer portal, no OpenAPI, and no documented API program.

## What API surface actually exists

- [SYNTAX Console GraphQL API](https://syntax.dnascript.com/graphql): the API behind DNA Script's
  SYNTAX Console Software — plate template design, oligo sequence upload, run scheduling and start,
  instrument fleet status and consumables, run reports, plus organization/user/group/project/license
  administration. 242 types; 70 queries, 64 mutations, 2 subscriptions. **Publicly reachable and
  anonymously introspectable, but every query and mutation returns 401 Unauthorized without a customer
  session.** It is a product API for SYNTAX owners, not a published developer API.

## Products

- [SYNTAX Platform](https://www.dnascript.com/products/): benchtop enzymatic DNA printer, up to 96 oligos in parallel, up to 120 nt.
- [SYNTAX Kits](https://www.dnascript.com/syntax-kits/): consumable reagent kits for the SYNTAX System.
- [ENCODEX](https://www.dnascript.com/encodex-dna-biomanufacturing-platform/): DNA biomanufacturing platform for larger-scale enzymatic DNA production.
- [Enzymatic DNA Synthesis technology](https://www.dnascript.com/technology/): the EDS chemistry and engineered polymerase behind both.
